# Entrenador de lectura · Grimorio del Tarot

Regalo de la guía digital **Grimorio del Tarot** de ABUMA.MA (@abuma.ma).

Practicá la lectura de las 78 cartas: interpretá cartas por tema y tocá los símbolos de los arcanos mayores.

Imágenes de las cartas: mazo Rider-Waite original de 1909, ilustrado por Pamela Colman Smith (dominio público).
